(`src/app/termos/page.tsx`), com link no rodapé. Ao trocar uma foto, atualize
os dois lugares.

não exige atribuição. Mesmo assim creditamos cada fotógrafo, aqui e no site.

Os arquivos do site são WebP com no máximo 1920 px no lado maior e menos de
300 KB cada. `og-dojo.jpg` e `og-estudos.jpg` (1200x630) são recortes das
mesmas fotos (Uriel Soberanes e Manuel Cosentino), em JPEG só para a prévia de
link (WhatsApp, redes sociais). Os originais em JPEG/PNG ficaram no histórico
do Git (commit anterior à conversão).

## Ao adicionar uma imagem nova

1. Converta para WebP abaixo de 300 KB.
2. Registre a linha na tabela acima e em Termos de Uso › Créditos das fotos.
3. Se a imagem vier de outra fonte, confirme que a licença permite uso
   comercial: o site é de um negócio real, não de um projeto pessoal.
4. Foto de aluno, sobretudo menor de idade, só com autorização de uso de
   imagem assinada (pelo responsável, no caso do menor).
